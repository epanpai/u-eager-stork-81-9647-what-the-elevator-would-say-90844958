## The entry

> I've heard your secrets, your arguments, your off-key singing. I know everything about you. I say nothing.

The elevator is the building's silent witness: it hears everything riders say inside it — secrets, arguments, off-key singing — and answers with a deadpan threat that lands on the last two words. Elevator-specific (it is the box you ride in), fresh (no "going down?" / ups-and-downs pun), and nothing to explain.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–120 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
